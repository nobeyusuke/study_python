条件分岐

Author

1 イントロダクション

試験の合格条件には絶対的な点数として定まっているものと周りの点数と比較して定まるものとがある。

ここで仮に「100点満点中60点以上だと合格」という試験に受験するとする。 このとき、

もし、試験の点数が60点以上なら・・・
    → 試験結果: 合格
そうでなければ・・・
    → 試験結果: 不合格

が成り立つ。

プログラムの世界でも同様に、条件によって異なる結果を実行させることが往々にしてある。 本節ではそんな条件分岐について学んでいこう。

2 if文

プログラミングの世界において、最も基本的かつ最も重要な条件分岐文はif文である。 ifの意味は皆さまご存じ「もし」であり、if文ではifのうしろに条件を書く。

例えば「試験の点数 (score) が60点以上」という条件を書きたいときには、

if (score >= 60): # ()は無くても良い

と書く。

つづいてif (条件):の下に条件を満たす場合に実行したいことを書く。 「試験結果: 合格」という文字列を出力したければ、

if (score >= 60):
    print("試験結果: 合格")

と書けばよい。

条件を満たさない場合に実行したいことがあれば、さらに下にelse:を書き、その下に実行したいことを書く。 「試験結果: 不合格」という文字列を出力したければ、

if (score >= 60):
    print("試験結果: 合格")
else: 
    print("試験結果: 不合格")

と書けばよい。

2.1 インデントの重要性

「条件を満たす場合に実行したいことはif (条件)の下に書く」と説明したが、

if (score >= 60):
print("試験結果: 合格")

だと条件分岐はできない。 正解のコードは、

if (score >= 60):
    print("試験結果: 合格")

であり、両コードの違いはprint("試験結果: 合格")の前の字下げ（インデント）にある。

Pythonではインデントがブロックの意味を果たすことになる。 例えば、

if (score >= 60):
    print("試験結果: 合格")

だと2行目のprint("試験結果: 合格")の前のインデントが「ifブロック」の意味を果たすことになり、

if (score >= 60):
    print("試験結果: 合格")
else:
    print("試験結果: 不合格")

だと2行目のprint("試験結果: 合格")の前のインデントが「ifブロック」、4行目のprint("試験結果: 不合格")の前のインデントが「elseブロック」の意味を果たすことになる。

難しいことはともかくとして、「Pythonで複数行のコードを書くときはインデントに気をつける」と覚えておこう。

2.2 関係演算子

第2節冒頭で「試験の結果 (score) が60点以上」という条件を書くとき、score >= 60と書いた。 このコードに含まれる>=は関係演算子というものの一種であり、「左辺は右辺より大きいか等しい」という意味を持つ。

その他、関係演算子には以下のようなものがある。 いずれの関係演算子もよく使われるため、すべて覚えておきたい。

関係演算子 意味
== 左辺と右辺は等しい
!= 左辺と右辺は等しくない
> 左辺は右辺より大きい
>= 左辺は右辺より大きいか等しい（左辺は右辺以上）
< 左辺は右辺より小さい
<= 左辺は右辺より小さいか等しい（左辺は右辺以下）

2.3 論理演算子

資格の中には科目が複数種類あり、そのすべてである程度の点数を取らなければならないというものもある。

たとえば資格Xに科目Aと科目Bがあり、「科目Aと科目Bの両方で1000点満点中600点以上」という合格条件があったとする。 このとき、

もし、科目Aが600点以上かつ科目Bも600点以上なら・・・
    → 試験結果: 合格
そうでなければ・・・
    → 試験結果: 不合格

が成り立つ。

これをプログラムで成立させるとき、andという論理演算子を用いることになる。 andは「かつ」を意味し、以下のように用いる。

if (A >= 600 and B >= 600):
    print("試験結果: 合格")
else:
    print("試験結果: 不合格")

その他、論理演算子には以下のようなものがある。 関係演算子と同様、いずれもよく使われるためすべて覚えておきたい。

論理演算子 意味
and かつ
or または
not でなければ

notの使い方だけ追加で学んでおこう。 第1節の資格の話を逆転して考えてみると、

もし、資格の点数が60点未満でなければ・・・
    → 試験結果: 合格
そうでなければ・・・
    → 試験結果: 不合格

が成り立つ。これはnotを用いれば、

if (not (score < 60)):
    print("試験結果: 合格")
else:
    print("試験結果: 不合格")

と表すことができる。

3 if-elif文

大学の授業では「合格（単位取得）・不合格（落単）」以外に「AA」や「A」などの評価が与えられる。

仮にこれらの評価がテストの点数に基づいて与えられる場合、

もし、テストの点数が90点以上なら・・・
    評価: AA
そうでなく、もしテストの点数が80点以上なら・・・
    評価: A
そうでなく、もしテストの点数が70点以上なら・・・
    評価: B
そうでなく、もしテストの点数が60点以上なら・・・
    評価: C
そうでなければ・・・
    評価: F

と表すことができる。

このような条件分岐をPythonで実行する場合、if-elif文という構文を使用する。

if-elif文の書き方は以下の通りである。

if (score >= 90):   # もしテストの点数が90点以上なら・・・
    print("評価: AA")
elif (score >= 80): # そうでなく、もしテストの点数が80点以上なら・・・
    print("評価: A")
elif (score >= 70): # そうでなく、もしテストの点数が70点以上なら・・・
    print("評価: B")
elif (score >= 60): # そうでなく、もしテストの点数が60点以上なら・・・
    print("評価: C")
else:
    print("評価: F")

なお、elifとはelse ifの略称である。 よって「そうでなく、もし〇〇なら」と解釈する。
